# Помічник зі складання бюджету

Навчальний прототип до програми «Перший успішний грант».

Сайт: https://lera-tatarchuk.github.io/isar-budget-helper/

Дані вводяться й зберігаються тільки у браузері користувача. Немає сервера збору бюджетів, автоматичного подання заявок чи аналітичних трекерів. Приклад містить лише навчальні суми. Порожня структура Excel вбудована для експорту; дані автора документа та конфігурація принтера вилучені. На practice.html опубліковано лише матеріали учасника: ТЗ, карту полів, стартовий запит і порожній Excel-шаблон без метаданих автора. Матеріали ведучої та внутрішні дослідження не публікуються.

Не є офіційним сервісом подання заявок. Трактування правила 20% потребує підтвердження власника програми. Брендинг та логотипи взято з офіційної сторінки ІСАР: https://ednannia.ua/tryvaiut-hrantovi-konkursy/pershyi-uspishnyi-hrant. Права на логотипи належать відповідним організаціям.

Оновлення: GitHub Pages публікує `main` / корінь. Після push дочекатися успішного deployment, потім оновити сторінку. Посилання постійне.
